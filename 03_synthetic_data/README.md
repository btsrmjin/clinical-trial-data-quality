# Synthetic Clinical Trial Dataset

## Overview

This folder contains a synthetic clinical trial dataset created for educational and portfolio demonstration purposes.

## Study

**Study:** A Randomized, Parallel-Group Study Evaluating a Lifestyle Intervention on Glycemic Control in Adults With Type 2 Diabetes

- Study type: Simulated randomized parallel-group trial
- Participants: 100
- Sites: 4
- Study duration: 12 weeks
- Visits: Week 0, Week 4, Week 8, Week 12

## Dataset

File:

`clinical_trial_dataset.csv`

The dataset contains synthetic participant-level clinical and demographic variables including:

- Participant identifiers
- Site information
- Demographics
- Anthropometric measurements
- Blood pressure
- HbA1c
- Fasting glucose
- Medication
- Adherence
- Adverse events

## Data Quality Framework

The dataset is accompanied by:

- `Data_Quality_Checks.md`
- `Validation_Results.md`
- `Query_Log.md`
- `Edit_Check_Specification.md`

These documents demonstrate a clinical data management workflow involving:

1. Data validation
2. Edit checks
3. Issue identification
4. Query generation
5. Query tracking
6. Data cleaning
7. Final dataset review

## Data Privacy

All records are synthetic and created solely for educational and portfolio purposes.

No real patient data or protected health information are included.
