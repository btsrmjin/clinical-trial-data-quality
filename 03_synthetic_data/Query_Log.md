## Query Status Definitions

- **Open:** Issue identified and requires review.
- **Resolved:** Data clarification or correction received.
- **Closed:** Query resolved and verified.

## Query Management Workflow

1. Identify potential data issue.
2. Assign query ID.
3. Document participant and variable.
4. Raise query.
5. Record response or correction.
6. Verify resolution.
7. Change status to Resolved.
8. Close query after verification.
