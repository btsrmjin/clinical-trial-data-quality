# Clinical Trial Data Quality & Query Management System

## Portfolio Project

A simulated clinical data management project demonstrating the workflow of structuring, validating, reviewing, querying, and cleaning clinical trial data.

> **Important:** This project uses 100% synthetic data for educational and portfolio purposes. No real patient data or protected health information are included.

---

## Study Overview

**Study Title:**  
A Randomized, Parallel-Group Study Evaluating a Lifestyle Intervention on Glycemic Control in Adults With Type 2 Diabetes

| Study Element | Description |
|---|---|
| Study type | Simulated randomized parallel-group clinical trial |
| Population | Adults aged 30–65 years with Type 2 Diabetes |
| Sample size | 100 participants |
| Study duration | 12 weeks |
| Study sites | 4 |
| Visits | Week 0, Week 4, Week 8, Week 12 |
| Primary outcome | Change in HbA1c from baseline to Week 12 |

---

## Project Objectives

This project demonstrates practical clinical data management activities, including:

- Clinical trial data structure
- CRF specification
- Data dictionary development
- Synthetic clinical dataset creation
- Data validation
- Edit-check design
- Clinical data query management
- Data cleaning documentation
- Final data quality review
